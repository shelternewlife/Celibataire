# Célibataire: Rencontres & Chat — official discovery site

GitHub Pages source for **Célibataire: Rencontres & Chat** by DevImpact.

- Website: https://shelternewlife.github.io/Celibataire/
- Google Play: https://play.google.com/store/apps/details?id=com.celibataire.single.devimpact
- Package: `com.celibataire.single.devimpact`

Run `python -m unittest discover -s tests -v`, `python scripts/build.py`, and `python scripts/validate.py`. The build generates eight localized markets, product pages, resource hubs, reciprocal hreflang, MobileApplication JSON-LD, robots.txt and XML/text sitemaps. Google Play is the source of truth for product claims.
